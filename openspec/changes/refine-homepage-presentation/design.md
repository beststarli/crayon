## Context

首页当前由单个 `.studio-scene` 通过 CSS 变量替换背景图；图片地址切换没有可插值的视觉过程，因此中央花田画作虽会淡入淡出，整桌背景仍会瞬间跳变。中央 `.artwork` 旋转约 `-1.2deg`，画纸底部容纳题签而比其他边更厚，且只在顶部放置两张贴纸。页眉操作区已有说明文字和主题按钮，可在同一组中加入两个外链入口。详见 `proposal.md`。

## Goals / Non-Goals

**Goals:**
- 在不替换现有四张首页主视觉素材的情况下精修装裱和主题过渡。
- 保持现有主题持久化、首屏构图与移动端信息优先级。
- 让新增外链入口复用现有玻璃控件语言，并满足键盘和屏幕阅读器使用需求。

**Non-Goals:**
- 不重新生成花田画作或桌面背景。
- 不增加站内 GitHub、博客内容页或第三方 API 集成。
- 不改变“开始创作”弹窗及其后续产品流程。

## Decisions

### 1. 使用两张常驻背景层交叉淡入

将白天和夜晚桌面作为两个绝对定位且同时存在的背景层，通过主题状态切换 `opacity`，过渡时长约 500–650ms，并使用缓入缓出曲线。两层常驻可确保浏览器对透明度插值，避免 CSS `background-image` 地址直接替换的跳变；两张资源继续预加载以降低首次切换闪烁。备选方案是对单一背景设置滤镜模拟夜晚，但会失去现有台灯和物件光照差异。

移动端仍保留顶部与底部取景策略，但每个取景位置都使用成对的白天和夜晚层交叉淡入。`prefers-reduced-motion: reduce` 下将过渡压缩到近乎即时。

### 2. 将画作与题签拆成两个视觉区域

移除画纸整体旋转。花田图放入具有统一内边距的正方正交纸框，使四侧白边共享同一个间距变量；原“花田 / 晴日”和 study 编号移至纸框下方的独立题签行或悬浮小标签，因此不占用底部白边。备选方案是继续把题签留在底边并压缩字号，但仍会破坏四边等宽的视觉判断。

### 3. 四角分别放置独立贴纸

使用四个装饰节点定位在左上、右上、左下、右下，胶带沿四角略微旋转并跨过纸张边缘；尺寸随画纸响应式缩放。贴纸不接收指针事件，且标记为装饰内容。它们使用适度透明度和阴影，在日夜桌面上都能被识别而不盖住花田主体。

### 4. 页眉外链使用紧凑圆形控件

GitHub 入口使用内联 GitHub 图标，博客入口使用用户提供的 128×128 WebP 头像，并以 `object-fit: cover` 裁成圆形。两者都使用真实链接、`target="_blank"` 与 `rel="noopener noreferrer"`，并设置中文 `aria-label` 与 `title`。头像源文件位于 `/var/folders/6m/jt_9shv141d98srjkbtn98640000gn/T/codex-clipboard-455edfc7-8752-48b7-a96a-358393b35651.webp`，实施时复制为稳定的项目内静态资源。

### 5. 为页眉说明文字使用独立主题令牌

新增浅色与深色分别定义的页眉说明颜色，而不是继续复用全局 `--ink`。浅色选择深棕绿或深墨绿并减少亮色文字阴影，保证位于咖啡附近亮背景时仍清晰；深色继续使用暖浅色。外链和主题按钮组成同一操作组，在手机上缩小间距并隐藏说明文字，但保留三个按钮。

## Risks / Trade-offs

- [两层背景同时存在会增加合成与显存成本] → 只对透明度做动画，保持图片尺寸和现有 WebP 压缩，不使用大范围模糊动画。
- [四角贴纸可能在小屏遮挡画面] → 使用响应式尺寸并只跨过白边与极少量画面，逐个检查 320px、390px 和桌面宽度。
- [页眉增加两个按钮后空间变紧] → 手机隐藏说明文字、缩小操作间距和控件尺寸，保证不发生横向滚动。
- [128×128 头像在高像素密度屏幕略显柔和] → 按钮显示尺寸控制在约 38–42 CSS 像素，不进行超尺寸放大。
